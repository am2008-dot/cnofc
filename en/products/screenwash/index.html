丝印洗网水RoHS

Screen Printing Mesh Wash

🧴丝印洗网水Screen Printing Mesh WashPhoto to be added; data per written technical sheet

Features

  • 专为丝网印刷网版清洗调配，对常用丝印油墨溶解力强。
  • 对感光胶与聚酯 / 不锈钢网纱温和，正常使用不伤版。
  • 可洗除网孔残留油墨，减少堵网与印刷缺陷。
  • 也用于刮刀、墨槽、工装上的油墨清理。
  • 配套产品：丝印油墨慢干水（783 型）。
  • 塑料件上的误印字符、油漆可用 CC-2X 塑料件专用脱漆 / 脱墨剂处理，不伤基材。
  • 按易燃溶剂管理，通风操作，废液按当地环保要求处置。
